# WhaleTalk

面向零基础操作者的大肥鱼互动直播项目。目标是在 Windows 上，用角色动画、B 站弹幕、DeepSeek、语音合成和 OBS，完成能回应观众、执行动作、响应礼物的虚拟角色直播。

## 当前进度

2026 年 11 月 13 日完成第一轮资料核查与方案设计。当前仓库交付技术方案、AI 开发约定、分阶段实施清单和操作指南，应用代码尚待实施。文档中的页面地址、配置项和命令若标注为“计划”，表示后续开发的目标入口。

## 直播怎样运转

```text
B 站弹幕 / 礼物
    ↓
接收事件 → 去重、筛选、排队
    ├─ 明确动作指令 / 礼物 → 动作映射与感谢模板
    └─ 聊天问题 → DeepSeek 生成简短回复与动作建议
                             ↓
                     校验回复 → 语音合成
                             ↓
                   角色动画 + 字幕 + 声音
                             ↓
                         OBS 推流
```

常见做法是播放提前准备好的动画，通过程序在待机、吃饭、跳舞、思考、说话等状态间切换。精确口型可以在后续增加 Live2D、3D 模型或音素驱动的口型系统。

## 推荐起点

采用“本机控制服务 + OBS 浏览器画面”的结构。先用模拟弹幕跑通，再接 DeepSeek、语音和真实 B 站事件。动画通过资源清单配置，便于替换角色。

源码采用模块化单体，服务端按事件、互动、播放、角色和设置划分业务模块，外部平台、模型与语音分别通过适配器接入。默认配置位于 `config`，用户配置、角色和运行数据位于 `data`。完整目录与依赖约定见 [项目结构](docs/PROJECT_STRUCTURE.md)。

已有 dsh-pet 用户还可以选择快速验证路线，使用其 HTTP 接口控制桌宠并由 OBS 捕获窗口。独立模式的对话接口会返回 `provider-missing`，接入 DeepSeek 由 WhaleTalk 服务承担。窗口透明效果和音频捕获需要在本机验证。[dsh-pet 接口](https://github.com/PC2005-cloud/dsh-pet/blob/main/API.md)

## 配置范围

- Windows 电脑、稳定网络和 OBS。
- 本地服务运行环境，推荐 Node.js 当前受支持的 LTS。
- DeepSeek API Key。
- 一种语音合成方案。原型可试用 edge-tts，持续运行可接正式云语音服务。
- 接入真实 B 站弹幕所需的房间信息，以及所选连接方式对应的登录信息或开放平台凭据。
- 角色动画与对应的使用授权。

## 素材授权

当前角色素材「大肥鱼 · 潮汐邮差」为本项目自制（ImageGen 辅助立绘 + 本地渲染导出），版权归项目操作者，可正常用于直播与收礼变现。旧 dsh-pet 素材已于 2026-11-21 移出项目（归档于项目外），不再使用。
