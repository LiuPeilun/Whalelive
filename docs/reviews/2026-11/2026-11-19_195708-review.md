## WT-P1-021 · P2 · 直播自动回退仍使用主动选择固定回复的来源标记

预览已改走严格路径。实测上游 401 和非法回复分别返回带具体原因的 502 `LLM_UNAVAILABLE`，挂起上游返回 504 `LLM_TIMEOUT` 并关闭连接。缺 Key 时配置返回 `DEEPSEEK_KEY_MISSING`，预览返回 502，配置面板具有对应提示。[预览入口](../../../src/server/transport/http/index.ts#L220) · [配置提示](../../../src/web/control/features/settings-panel.ts#L75)

直播路由捕获错误后直接返回固定提供方的结果，来源仍为 `fixed-local`。通过实际模拟弹幕入口复现，选中 DeepSeek 时，上游 401、非法 JSON 和标记截断均触发保底回复，队列状态的 `metrics.last.provider` 都为 `fixed-local`。同一实例手动切换为固定回复后得到相同标记。配置仍显示 DeepSeek 为当前生效来源，操作者无法从队列区判断某条直播回复是否因模型故障降级。P1 验收条目规定该路径显示 `fallback`。[自动回退](../../../src/server/integrations/llm/reply-router.ts#L50) · [队列展示](../../../src/web/control/features/queue-view.ts#L70) · [P1 验收](../../ROADMAP.md#L83)

自动回退时保留固定文本并标记来源为 `fallback`，让主动选中的离线模式仍返回 `fixed-local`。从真实模拟弹幕入口复验缺 Key、上游故障及主动离线三种状态。

## WT-P1-022 · P2 · 真实适配器仍丢弃非法或截断回复的 token 用量

阶段计时和正常模型响应后的停止已复验。受控延迟样本分别记录排队 241 毫秒、生成 260 毫秒、合成 20 毫秒和播放阶段 736 毫秒，总计 1257 毫秒。规则回复未请求模型，合成记录 25 毫秒。模型成功返回 32 token 后在等待播放时停止，当前任务仍保留该用量，累计正确从 32 增至 64，迟到的取消回执未重复计数。[阶段差值](../../../src/server/modules/interaction/index.ts#L135) · [入账](../../../src/server/modules/interaction/index.ts#L341) · [停止记录](../../../src/server/modules/interaction/index.ts#L491)

真实 DeepSeek 适配器仍在格式校验及截断判断后才读取 `usage`。一条 HTTP 200 响应内含非法 JSON 和 32 token，另一条内含完整 JSON、`finish_reason: 'length'` 和 32 token。两条均通过实际服务降级，任务用量均为空，累计仍为 64。新增的用量单测直接让提供方返回含空 `say` 和 `usage` 的结果，绕过了生产适配器抛错和路由返回固定回复的路径。[适配器响应处理](../../../src/server/integrations/llm/deepseek.ts#L127) · [现有用量单测](../../../src/server/modules/interaction/dispatch.test.ts#L251)

将已经取得的上游用量随可区分的回退结果或类型化错误传到直播编排器，在同一请求上累计一次。预览继续报告格式错误。用真实适配器与假端点验证，端点上报 32 token 后，直播使用保底内容，累计用量增加 32。
