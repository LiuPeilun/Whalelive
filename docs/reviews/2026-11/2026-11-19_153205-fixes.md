# 修复记录 · 2026-11-19_153205

对应审核为 [P1 第二批 edge-tts 代码审查](2026-11-19_153205-review.md)。WT-P1-015～019 已修复并验证，等待复审。接手时 Zcode 已在当前分支完成按音色管理实例、基础超时、SSML 转义、音色校验和设置恢复的主体改动，工作区有 87 项测试通过。本次沿现有实现补齐了迟到请求的归属、底层列表请求取消、设置恢复和退出状态，并运行实际接口与浏览器回归。

## WT-P1-015 · 试听干扰直播音色与在途合成

**修复**。按音色复用客户端，请求在握手和合成期间持有实际实例。旧连接返回错误时，只退役该请求使用的实例，引用归零后关闭。迟到错误与重试均复用仍可用的替换连接。空闲客户端最多保留四个，正在合成的连接按请求完成时机收尾。[适配器](../../../src/server/integrations/tts/edge-tts.ts)

**复验**。受控用例覆盖握手时切换音色、直播已经开始合成时试听、同音色旧实例迟到失败，以及服务关闭时取消在途工作。晓晓和云健各用自己的实例，迟到重试仍使用已经建立的替换实例。[测试](../../../src/server/integrations/tts/edge-tts.test.ts)

## WT-P1-016 · 试听与音色列表超时

**修复**。试听的信号覆盖初始化、重试及音频流。中止时关闭本次创建的握手实例，或销毁本次音频流。列表沿用锁定版本 `msedge-tts@2.1.1` 的请求地址，改用原生 `fetch` 将 8 秒超时信号传给 HTTP 请求，并为并发列表调用复用在途请求。服务关闭时取消合成与列表请求，关闭空闲客户端。路由分别映射 `TTS_TIMEOUT` 和 `TTS_UNAVAILABLE`。[适配器](../../../src/server/integrations/tts/edge-tts.ts) · [HTTP 路由](../../../src/server/transport/http/index.ts)

**复验**。实际 HTTP 入口把试听超时设为 100 毫秒，握手永远挂起时约 155 毫秒返回 504，握手实例已关闭，下一次试听返回 200。挂起本地音色列表上游时，约 8 秒返回 504，上游确认连接已关闭，解除故障后列表恢复 200。

## WT-P1-017 · 普通文本造成 SSML 解析失败

**修复**。在适配器边界转义 XML 文本字符，剔除 XML 1.0 非法字符，保留 emoji 和合法补充区汉字。直播合成与试听调用同一转换逻辑。[文本转换](../../../src/server/integrations/tts/speech-text.ts)

**实测**。真实 Edge 试听含 `&`、`<` 和鱼 emoji 的普通短句返回 200，媒体返回 `audio/mpeg`，文件为 31824 字节，Range 返回 206。

## WT-P1-018 · 可试听的音色无法保存

**修复**。音色列表、试听和设置保存共用短名校验，接受地区变体和书写系统。列表过滤不符合该规则的选项，试听拒绝不合法的覆盖参数。[共享音色契约](../../../src/shared/settings.ts) · [设置校验](../../../src/server/modules/settings/schema.ts)

**实测**。在线列表返回 318 项，`zh-CN-liaoning-XiaobeiNeural` 出现在列表中，实测试听和保存均返回 200，设置重读确认选中的音色已生效。覆盖音色类型非法返回 400，播放端凭据访问试听返回 401。

## WT-P1-019 · 晚待机回归结束后语音设置未恢复

**修复**。晚待机脚本保留临时切换策略，在 `finally` 中等待恢复并重读核对，同时保留并发修改。恢复失败会让命令失败。正常结果沿入口返回，浏览器与调试端口由本次测试独立使用，清理按本次浏览器归属执行。[晚待机回归脚本](../../../scripts/e2e-late-idle.mjs)

**实测**。隔离服务与真实 Edge 上，脚本正常完成并退出 0，辽宁音色和原语音提供方均恢复。模拟浏览器启动失败时，脚本退出 1，恢复 `edge-tts` 与原音色，并保留运行期间另行保存的队列容量。临时切换和恢复都是设置写入，因此设置版本会递增。
