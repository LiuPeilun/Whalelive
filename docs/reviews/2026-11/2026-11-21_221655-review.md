# P2 互动玩法第一批修复复审

本轮复审通过。WT-P2-001 保持关闭，WT-P2-002 和 WT-P2-003 关闭。审查覆盖 `main` 从 `fef25d4` 到 `3c729d3` 的一个提交，复验未发现本轮改动引入的实质回归。[上轮审核](2026-11-21_213859-review.md) · [本轮修复记录](2026-11-21_213859-fixes.md)

## WT-P2-001 · 保持关闭 · 直播答谢专属动作

回环假模型返回 `stamp-letter` 时，普通弹幕保留模型文案并派发 `talk`。控制台手动试播仍可派发 `stamp-letter`。自动回复的动作限制与授权手动试播权限均符合第一批约定。[直播采纳](../../../src/server/modules/interaction/index.ts#L381) · [手动试播](../../../src/server/transport/http/index.ts#L252)

## WT-P2-002 · 关闭 · 回复预览与可播放动作

回复预览和普通弹幕派发共用动作校验。隔离实例故意省去 `spin.webm`，让假模型依次返回缺素材的 `spin`、待机 `idle`、专属 `stamp-letter` 和未登记动作，预览均保留文案并将动作置空。可用的 `talk-nod` 正常保留，普通弹幕也能派发该口型。对缺素材的 `spin` 手动提交试播，服务端返回 HTTP 400 和 `ASSET_MISSING`，没有生成当前播放任务。[共享校验](../../../src/server/modules/interaction/index.ts#L26) · [预览接口](../../../src/server/transport/http/index.ts#L234) · [试播拒绝](../../../src/server/transport/http/index.ts#L258)

Edge 控制台显示 19 个动作，只有 `spin` 显示「素材缺失」并被禁用。`salute` 和 `stamp-letter` 仍可选择。[试播下拉框](../../../src/web/control/features/manual-action.ts#L24)

## WT-P2-003 · 关闭 · 含彩蛋词的普通提问

通过模拟弹幕入口发送「为什么要喝口茶？」「吃饭前喝口茶对肠胃有影响吗？」「敬个礼和打个招呼有什么区别？」，每条都调用假模型一次并派发 `talk`。单独发送「敬个礼」「喝口茶」仍分别派发 `salute`、`sip-tea`。旧指令样本「来跳个舞」「今天吃什么」仍派发 `dance`、`eat`，四条确定性指令均跳过模型。[口令优先级](../../../src/server/modules/interaction/rules.ts#L41)
