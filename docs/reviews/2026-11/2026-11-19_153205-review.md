# P1 第二批 edge-tts 代码审查

edge-tts 已接入现有语音提供方接口、音频缓存和媒体入口。实际服务可列出音色、试听并返回可读取的 MP3，固定本地提供方与 edge-tts 的设置热切换成功。本批审查结论为需修复，共 1 项 P1、4 项 P2。首要问题是控制台试听与直播回复共用可变客户端，能让已经开始的回复用错音色，或中断在途合成。[P1 第一批复审通过记录](2026-11-19_135548-review.md) · [第二批路线图](../../ROADMAP.md#L216)

## WT-P1-015 · P1 · 控制台试听能改变直播回复的音色或中断合成

`readyClient()` 在等待音色初始化前写入全局 `client`，异步返回时又读取该全局变量。直播合成、换音色试听和音色列表请求都可调用同一适配器。另一调用可以在等待期间换掉或关闭客户端，错误重试也会关闭当时的全局实例。使用实际适配器和可控客户端复验，直播回复请求晓晓音色，控制台同时试听云健，两个请求均返回成功，直播回复却交给了云健客户端合成。另一用例在直播音频流已经开始后试听云健，初始语音流被关闭，直播重试又关闭了试听所用的连接。锁定版本 `msedge-tts@2.1.1` 的 `close()` 会销毁未完成的语音流，测试替身复现了该行为。[共享客户端及音色初始化](../../../src/server/integrations/tts/edge-tts.ts#L38) · [错误时重连](../../../src/server/integrations/tts/edge-tts.ts#L98) · [直播与试听的装配](../../../src/server/app.ts#L87)

让每项请求持有稳定的客户端与音色，重试仅失效本次请求使用的实例。试听和列表查询应避免关闭直播在用连接。回归需同时覆盖握手中换音色、语音流开始后试听，以及旧请求失败时新实例继续可用。

## WT-P1-016 · P2 · 试听和音色列表的超时未覆盖外部等待

试听调用设置了 `AbortSignal.timeout`，但适配器先等 `setMetadata()`，之后才判断信号。实测将超时配置设为 100 毫秒，连接替身约 950 毫秒后拒绝，实际 HTTP 约 1055 毫秒才返回 504。连接初始化和重试因此可以超过配置期限。音色列表还先等待同一个合成连接，再调用依赖包的 `getVoices()`。该版本使用未指定请求超时的 Axios GET，应用层也无截止。列表拉取遇到迟滞时，设置页面等不到失败提示，未完成的请求还会拖长服务关闭。[试听信号装配](../../../src/server/app.ts#L92) · [合成等待与列表读取](../../../src/server/integrations/tts/edge-tts.ts#L87) · [音色列表路由](../../../src/server/transport/http/index.ts#L133)

让试听的截止覆盖握手、重试和音频流，信号失效后及时结束对应工作。列表查询使用独立有界的外部请求，按实际失败原因返回稳定错误码。用挂起握手和挂起列表请求做回归，并检查后续请求仍可恢复。

## WT-P1-017 · P2 · 普通文本中的符号会使合成请求失效

适配器将普通文本直接传入 `MsEdgeTTS.toStream()`，锁定版本会把输入原样拼到 SSML。受控复验用该包的实际模板，确认普通短句里的 `&` 原样进入 XML。真实接口的正常文本前后均返回 200 并生成可读取 MP3，夹在中间的含 `&` 普通短句返回 502。礼物感谢词还会包含观众昵称与礼物名称，同样会经过这条路径。[适配器的文本透传](../../../src/server/integrations/tts/edge-tts.ts#L87) · [礼物感谢词](../../../src/server/modules/interaction/rules.ts#L43)

在 TTS 边界按普通文本构造 SSML，转义 XML 文本字符并处理不合法控制字符。音色覆盖参数也应经过统一的音色输入校验后再送入库。回归用实际常见符号覆盖直播和试听入口。

## WT-P1-018 · P2 · 部分真实音色可试听但无法保存

实际 `GET /api/tts/voices` 返回 318 项，其中 6 项不符合设置端只接受三段的短名规则，包括两个中文方言音色。实测 `zh-CN-liaoning-XiaobeiNeural` 可以试听，语音媒体返回 200 与 `audio/mpeg`，用同一个短名保存设置却返回 400。控制台把该值展示成普通可选项，用户可试听成功但不能用于直播。[音色列表读取](../../../src/server/integrations/tts/edge-tts.ts#L125) · [音色设置校验](../../../src/server/modules/settings/schema.ts#L52) · [音色下拉](../../../src/web/control/features/settings-panel.ts#L73)

统一音色列表、试听和保存的短名契约。覆盖带地区变体或书写系统的服务端真实短名，或在下拉展示前过滤不可保存的选项。回归验证同一选项可以从列表选择、试听并保存。

## WT-P1-019 · P2 · 晚待机回归会把运行服务留在 fixed-local

脚本通过 PUT 持久化切换到 `fixed-local`，恢复放在异步 `process.on('exit')` 回调。正常和异常路径都显式调用 `process.exit()`，Node 退出时不会等回调里的 HTTP 请求完成。在隔离的真实服务上执行原脚本，仅用替身阻断浏览器调试连接，避免启动或停止现有浏览器。脚本按预期退出 1，服务配置却从 `edge-tts` 留在 `fixed-local`，版本从 0 变为 1。操作员若用日常服务跑这条回归，之后直播会继续使用本地罐头音。[切换与退出恢复](../../../scripts/e2e-late-idle.mjs#L67) · [正常和异常退出](../../../scripts/e2e-late-idle.mjs#L200)

优先从测试夹具启动时使用独立数据目录和预置设置。若测试入口必须临时改运行服务的设置，应在 `finally` 中等待恢复并验证结果，保持其他字段与并发修改。回归覆盖测试完成与浏览器连接失败两条路径，并检查语音提供方及音色恢复。
