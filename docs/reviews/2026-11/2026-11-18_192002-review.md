# P1 第一批第四轮修复复审

原断线复现使用 650 毫秒旧页处理延迟，本轮已通过。主动释放实测确认先停声再发消息。WT-P1-004 仍存在边界缺口，断线后的固定等待可以早于旧租约截止，旧页处理延迟更长时仍能同播。新增重连改动另有 1 项 P1、2 项 P2。其余已关闭的历史问题沿用前轮结论。[前轮复审](2026-11-18_175515-review.md) · [修复记录](2026-11-18_175515-fixes.md)

## WT-P1-004 · P1 · 未确认停声的断线接管早于旧租约截止

`unregister()` 使用 `now + takeoverSafetyMs` 取代被清除租约的期限。真实 Edge 双页使用 3000 毫秒租约和 800 毫秒安全等待。旧页播放中关闭业务 WebSocket，保留该页面，将它对关闭事件的处理延迟 1500 毫秒。新页在服务端发现断线约 1010 毫秒后已经起播，距旧租约原到期仍约 1182 毫秒。采样时旧页尚未处理关闭事件，两页均在播放且未静音。[断线接管期限](../../../src/server/modules/playback/renderer-lease.ts#L37) · [页面断线处理](../../../src/web/overlay/main.ts#L213) · [转交约定](../../ARCHITECTURE.md#L230)

应保留未确认停声的旧租约安全截止，再依据旧端真实停声确认提前解除等待。复测需要覆盖关闭事件处理延迟超过配置窗口、正常到期回收，以及已经停声的主动释放。页面卸载路径已经在发送 `lease-release` 前执行本地停止，保留这个顺序。[主动释放](../../../src/web/overlay/main.ts#L229)

## WT-P1-009 · P1 · 重连诊断脚本会强制停止其他项目的进程

`e2e-reconnect-trace.mjs` 通过 WMI 枚举整台电脑的 `node.exe`，排除脚本自身后，向命令行含 `tsx` 的进程发出强制终止。传入端口只用于后续健康检查。用合成进程记录核对选择条件时，另一个工作区的 `tsx` 开发服务和 WhaleTalk 测试服务都被选中。已有的 `e2e-reconnect-idle.mjs` 第一阶段也使用相同筛选条件。本轮通过读取代码和合成记录核对，实际运行均使用独立测试服务。[新诊断脚本](../../../scripts/e2e-reconnect-trace.mjs#L52) · [已有重连脚本](../../../scripts/e2e-reconnect-idle.mjs#L135)

让重连诊断只停止脚本启动并持有的测试进程，或依据明确传入的 PID 校验目标服务归属。用两个独立测试进程验证目标停止、旁路进程继续运行。

## WT-P1-010 · P2 · 自愈重载失败会中断页面的恢复能力

第三次 WebSocket 握手超时后直接调用 `location.reload()`，没有先确认页面文档已经可用。用真实 Edge 将前三次业务握手导向本机悬挂连接，缩短守卫计时用于定向验证，并让触发的那一次文档重载返回 HTTP 503。确认自愈已触发，之后取消 503 注入，服务健康检查返回 200。浏览器仍留在 503 文档，探针消失，播放端数量保持 0。手动刷新后立即恢复登记。[自愈触发与重载](../../../src/web/shared/ws-client.ts#L56)

重载应有明确的页面可用依据，服务暂不可用时需保持原页继续重试。验收应覆盖握手挂起与页面文档同时暂不可用后自动恢复。当前 `e2e-selfheal-verify.mjs` 即便观察不到恢复也返回 0，适合作观察记录时需按日志判读。若作为回归入口，失败场景应返回非零。[观察脚本退出](../../../scripts/e2e-selfheal-verify.mjs#L56)

## WT-P1-011 · P2 · 诊断输出会记录播放和控制台凭据

重连轨迹输出直接截取 `location.href` 和 CDP 目标 URL 的前缀，播放页的 fragment 进入日志。用 32 字符合成凭据检查默认端口格式时，70 字符截取仍包含其中 31 字符。更直接的是重启服务的标准输出写入 `.tools/trace-server.log`，启动横幅会输出含完整凭据的控制台和播放页链接。诊断日志原样分享时会带出凭据。[页面 URL 输出](../../../scripts/e2e-reconnect-trace.mjs#L94) · [服务日志重定向](../../../scripts/e2e-reconnect-trace.mjs#L84) · [启动横幅](../../../src/server/main.ts#L38)

轨迹应只输出必要的路径和非敏感状态。服务日志落盘前过滤含凭据的启动链接。使用合成凭据验证控制台、CDP 目标列表和生成的日志文件都不包含凭据。
