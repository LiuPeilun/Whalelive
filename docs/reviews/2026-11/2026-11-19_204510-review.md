## WT-P1-021 · 直播降级来源

通过实际模拟弹幕入口与状态快照验证，选择 DeepSeek 但缺 Key、上游 401 和回复内容不可用时均显示 `fallback`。缺 Key 的场景对假端点发起 0 次请求。主动选择固定回复时仍为 `fixed-local`，模型成功回复仍为 `deepseek`。预览对非法、截断内容返回 502 `LLM_UNAVAILABLE` 并给出对应原因。[直播路由](../../../src/server/integrations/llm/reply-router.ts#L50) · [预览路由](../../../src/server/integrations/llm/reply-router.ts#L77)

## WT-P1-022 · 模型用量传递与计数

真实适配器在内容校验前读取上游用量，内容不可用时随类型化错误送到路由，再随保底回复交给既有编排器记账。[读取用量](../../../src/server/integrations/llm/deepseek.ts#L127) · [降级结果](../../../src/server/integrations/llm/reply-router.ts#L64) · [一次记账](../../../src/server/modules/interaction/index.ts#L341)

| 假端点响应或操作 | 直播来源 | 本次累计增量 |
| --- | --- | --- |
| HTTP 401，未携带用量 | `fallback` | 0 |
| HTTP 200，非法 JSON，32 token | `fallback` | 32 |
| HTTP 200，空内容，32 token | `fallback` | 32 |
| HTTP 200，完整 JSON 但标记 `finish_reason: 'length'`，32 token | `fallback` | 32 |
| HTTP 200，有效回复，32 token | `deepseek` | 32 |
| 非法回复已降级，等待播放时紧急停止 | `fallback` | 32，迟到取消回执后总数保持为 160 |

每条直播请求在假端点仅接收一次。被截断的模型文本未进入待播内容。非法、截断回复在预览中报错，直播统计值保持原值。
