## WT-P2-017 · P2 · 旧版自选音色在升级后被附加新的默认音调

`defaults.json` 将默认音色定为晓伊 `+20Hz`。设置加载逐字段合并 TTS 对象，旧版用户保存的自选 `voice` 会留下，旧对象缺失的 `pitch` 却从新默认值补成 `+20Hz`。直播合成按这个组合调用 Edge，控制台保存任意设置时还会把合并后的音调一同写回。旧版显式选择的音色听感发生变化，设置页没有音调控件可直接恢复。[版本默认值](../../../config/defaults.json#L38) · [设置合并](../../../src/server/modules/settings/index.ts#L89) · [Edge 合成](../../../src/server/integrations/tts/edge-tts.ts#L154) · [面板保存](../../../src/web/control/features/settings-panel.ts#L253)

用独立设置目录、实际设置模块和 Edge 合成适配器复验。客户端替身记录 `setMetadata()` 的音色及 `toStream()` 的韵律参数。旧文件只保存 `edge-tts` 与辽宁小北音色，基准版无音调偏移，新版发出了辽宁小北 `+20Hz`。干净目录正确发出晓伊 `+20Hz`，旧文件显式保存 `pitch: ""` 时仍无偏移。复验条件是旧版显式自选音色且从未保存音调时保留零偏移，显式保存的音调继续生效，干净目录仍取新默认音色组合。

## P3 唱歌原型与音区验证

操作者提供的背景记录了 B 站搜歌、分离、切片、换声和清唱原型实测。本机核对到 RVC 运行时、分离人声和 `+6`、`+8` 清唱样本。`58ece40` 的唱歌相关提交范围为训练语料文本和训练记录，应用的弹幕点歌、后台处理、队列接替及 OBS 播出仍待集成验收。清唱是当前已选定路线。

在 RVC 自带 Windows x64 CPython 3.12.10、NumPy 1.26.4 中，从 PyPI 下载 `pyworld-0.3.5-cp312-cp312-win_amd64.whl` 并核对 SHA-256。通过 PowerShell 解包到临时目录，在 Python 脚本内把解包目录加入 `sys.path` 后导入成功。五句现有晓伊语料以单声道 24 kHz 解码，使用 Harvest、CheapTrick 和 D4C 分析。每句按其中位数计算倍率，仅缩放非零基频，并用原谱包络、非周期性参数合成。Harvest 复测中位数由 304.1–360.5 Hz 降至 202.6–207.7 Hz，时长变化不超过 0.01 秒，有声帧占比变化绝对值不超过 4.7 个百分点。该实验验证了运行环境与降调能力。低音样本的晓伊相似度、RVC 训练效果和实际歌声 `key=0` 听感均待盲听。[PyWORLD 发行文件与算法说明](https://pypi.org/project/pyworld/0.3.5/)

推荐先给同一批干声制作 WORLD 原调重合成、WORLD 降调、Rubber Band R3 保共振峰降调，并用原始干声和已有变速降调作为对照。WORLD 原调重合成能量化重合成本身的影响。跨内容、跨说唱的平均 MFCC 和谱质心只适合粗筛。同句对齐后可比较有声元音的 F1/F2 和清浊边界，并以响度匹配的盲听决定是否扩充语料。反复出现在训练样本里的合成伪影可能被学进去。Rubber Band 官方 Windows 命令行可直接做对照，Praat 的 TD-PSOLA 也可将共振峰比例设为 1，只调整音高和指定时长。[Rubber Band Windows 下载](https://breakfastquay.com/rubberband/) · [R3 与共振峰选项](https://github.com/breakfastquay/rubberband/blob/default/main/main.cpp) · [Praat](https://www.fon.hum.uva.nl/praat/manual/Sound__Change_gender___.html)

RVC 本地版本将按半音缩放后的 F0 作为生成器条件，还可以单独调整索引混合；现有听感差异无法定位到某个生成器组件。训练对照可保留原语料，加入盲听通过的 205 Hz 附近和中间档同句变体，固定索引和推理参数，用同一段真实歌声直接 `key=0` 盲听。等低音目标波形可信后再考虑低音加权。另一条无需重训的比较是让现有模型先在熟悉的音区生成，再对输出做保共振峰的反向移调以回到原调。该比较验证成片，模型直接 `key=0` 的验收仍单独进行。[RVC 官方推理实现](https://github.com/RVC-Project/Retrieval-based-Voice-Conversion-WebUI/blob/main/infer/vc/pipeline.py)

清唱可优先比较男声段落的 `+12` 与 `+15`。输入中位 130 Hz 时分别约为 260 和 309 Hz。`+12` 保留音级和原调，`+15` 的音级等同于升 3 个半音。候选应按有声帧落入可用音区的比例比较。单个全段移调无法把 143–277 Hz 的相同曲线完整塞入 248–403 Hz，宜先选择合适的片段。若保共振峰语料仍未通过，可用晓伊干声参考试验唱歌预训练的零样本 SVC，如 HQ-SVC。DiffSinger 适用于已有歌词、音符与时值的合成路线。两个方向的本机 CPU 耗时与晓伊相似度均待实测。[HQ-SVC](https://arxiv.org/abs/2511.08496) · [DiffSinger](https://github.com/MoonInTheRiver/DiffSinger)
